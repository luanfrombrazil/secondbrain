# Decisões

| # | Decisão | Data |
|---|---|---|
| D-01 | O projeto é um aplicativo de notas independente, diferente do Obsidian. Não faz parte do Overtimer e não usa o Oráculo. | 06/11/2026 |
| D-02 | A fase atual é só de planejamento: ideias e protótipos no Figma, sem código. | 06/11/2026 |
| D-03 | A tela principal é um grafo de cards. Cada trilha é uma camada independente. | 06/11/2026 |
| D-04 | Cada camada começa como uma tela plana infinita. O 3D, com as camadas empilhadas, fica para uma versão futura. | 06/11/2026 |
| D-05 | Posição: horizontal = profundidade de pré-requisitos; vertical = área. | 06/11/2026 |
| D-06 | Três forças de conexão: forte (linha com seta), média (só a posição) e fraca (tracejada, só de perto). | 06/11/2026 |
| D-07 | O estado do card aparece só por uma faixa colorida no topo: azul em andamento, amarelo disponível, vermelho bloqueado, verde estudado. | 06/11/2026 |
| D-08 | Os cards são opacos, com uma sombra branca bem leve, sobre um fundo quadriculado. | 06/11/2026 |
| D-09 | O card de uma trilha interna é o mesmo componente do card de fora (trilha dentro de trilha). Os cards sem trilha própria não têm o botão maximizar. | 06/11/2026 |
| D-10 | O zoom semântico tem níveis. No muito afastado, os cards viram bolinhas agrupadas por área, com tamanho pelo conteúdo e nome no hover. | 06/11/2026 |
| D-11 | O arquivo PDF é um card comprido, com prévia 9:16 e expandir para ver as informações. | 06/11/2026 |
| D-12 | As notas são `.tex` no estilo `article` (Computer Modern) e usam só LaTeX padrão, sem comandos ou pacote próprios. | 06/11/2026 |
| D-13 | O `\author` da nota é a pessoa (Luan Lana Maia). O título do card é separado do título da nota e do nome oficial da disciplina. | 06/11/2026 |
| D-14 | A nota abre no grafo como um papel lateral (espiar → ao lado → página dupla). A página dupla separa as folhas só por um espaço pequeno. | 06/11/2026 |
| D-15 | A barra do editor LaTeX usa ícones em grupos: desfazer/refazer, estilo, negrito/itálico, matemática/símbolos, link/comentário/rótulo/citação/figura/tabela, lista. | 06/11/2026 |
| D-16 | Uma nova trilha é criada direto na árvore, com o campo de nome aberto, sem diálogo. | 06/11/2026 |
| D-17 | As informações da nota que não são texto são editadas num editor do card que abre no lugar do card (clique duplo ou criação), com o PDF ao lado e uma interface única com card, `.tex` e PDF. | 06/11/2026 |
| D-18 | A stack é Java 25, JavaFX e Maven. Ver [stack](stack.md). | 07/11/2026 |
